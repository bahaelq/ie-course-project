# Unlabeled Corpus

**Zweck:** Übrige Stellenanzeigen ohne Annotation, vorgesehen für Weak Labeling.

**Struktur:**
- `texts/` – Rohtext der Stellenanzeigen (`.txt`, UTF-8)

**Kriterien:**
- Keine Überschneidung mit `data/example_pool/`, `data/gold/` oder `data/smoke_test/`
- Keine zugehörigen Annotationen in diesem Split
